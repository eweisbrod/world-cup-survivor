# NCAA Survivor Pool — March Madness 2026

A real-time NCAA March Madness survivor pool web app.

## How It Works
- Pick one team to win each day of the tournament
- If your team wins, you survive to the next day
- You can only use each team **once** the entire tournament
- If your team loses, you're eliminated

## Features
- Firebase Realtime Database for shared picks across all players
- Live score fetching from NCAA API with auto-refresh
- Board view to see all players' picks at a glance
- Mobile-first dark UI
